# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What This Is

Airwindows is a collection of 500+ open-source audio DSP plugins (VST2/AU) by Chris Johnson, MIT licensed. Plugins cover mixing, mastering, saturation, reverb, clipping, dithering, and creative effects across 22 categories. No UI — pure audio processing; UIs are handled by the host DAW.

## Build Commands

### Linux VST (CMake)

Requires VST2 SDK placed at `plugins/LinuxVST/include/vstsdk/` (Steinberg license prohibits redistribution).

```bash
cd plugins/LinuxVST
mkdir build && cd build
cmake ..
make
```

Outputs `.so` files. Add new plugins by creating `src/PluginName/` with `.cpp`/`.h` files and adding `add_airwindows_plugin(PluginName)` to `plugins/LinuxVST/CMakeLists.txt`.

### macOS AU (Xcode — all plugins)

```bash
./scripts/build_all_au.sh
```

Requires CoreAudio Extras headers (see `scripts/setup_coreaudio_extras.sh`). Installs built plugins to `~/Library/Audio/Plug-Ins/Components/`. Logs errors and reports summary on completion.

### macOS AU or VST (single plugin)

Open the `.xcodeproj` in `plugins/MacAU/<PluginName>/` or `plugins/MacVST/<PluginName>/` and build Release/x64 in Xcode.

### Windows VST (Visual Studio)

Open `plugins/WinVST/<PluginName>/VSTProject.sln` in Visual Studio, build Release/x64.

### Create macOS Installer

```bash
./scripts/create_installer.sh
```

## Plugin Architecture

Every plugin follows the same structure across all platforms. Platform-specific wrappers differ; DSP code is identical.

**Per-plugin files:**
- `PluginName.h` — class definition
- `PluginName.cpp` — lifecycle + parameter methods
- `PluginNameProc.cpp` — DSP processing (VST only; AU folds this in)
- `PluginNameVersion.h` — version info (AU only)

**Base classes:**
- VST2 (Linux/Mac/Windows): `AudioEffectX` (Steinberg VST2 SDK)
- AU (macOS): `AUEffectBase` (Apple CoreAudio)

**Key patterns used consistently across all plugins:**

1. **Dual-precision processing** — separate `processReplacing()` (float) and `processDoubleReplacing()` (double) implementations
2. **Chunked preset serialization** — binary `getChunk()`/`setChunk()` for cross-platform preset portability
3. **Parameters as floats A–Z** — parameter values stored as private `float A, B, C...` members; `kParamA`, `kParamB` enum IDs
4. **Four-character unique ID** — every plugin declares `const unsigned long kUniqueId = 'xxxx'` (used by AU for identification)
5. **No external dependencies** — pure C++ standard library only; all DSP hand-written

## Documentation

`docs/` contains a static SPA (HTML/JS/CSS) with real-time search across all plugins. Data lives in `docs/data/plugins.json` (944 KB) and is generated by:

```bash
python3 parse_data.py        # Airwindopedia.txt + what.txt → plugins.json
python3 generate_plugin_docs.py   # plugins.json → docs/plugins/*.md
python3 generate_category_docs.py # → docs/categories/*.md
```

`Airwindopedia.txt` is the authoritative plugin database (1.1 MB). `what.txt` is a quick-reference summary.

## Adding a New Plugin

1. Copy from `plugins/Templates/` (AU, MacVST, or WinVST zip templates)
2. Implement DSP in `processReplacing()` and `processDoubleReplacing()`
3. Declare parameters with `kParamA`/`kParamB` enum and `float A, B` members
4. Choose a unique four-character ID
5. For Linux: add source files to `plugins/LinuxVST/src/PluginName/` and register in `CMakeLists.txt`
6. For macOS AU: add to `plugins/MacAU/` and register in `scripts/build_all_au.sh`

## No Automated Tests

There is no test suite. Plugin validation is done manually in a DAW or via `auval` (Audio Unit Validator, macOS):

```bash
auval -v aufx XXXX Airw   # replace XXXX with the plugin's four-char ID
```

## Build system

Managed by Bombest. Config at `.bombest-plugin-builder/build.json` (committed — no secrets).

| Command | What it does |
|---|---|
| `/bombest:build --tier dev` | Ad-hoc signed AU build via `scripts/build_all_au.sh` |
| `/bombest:build --tier release` | Notarized build + installer via `scripts/create_installer.sh` |
| `/bombest:deploy` | Upload installer to `s3://bombest-releases` |
| `/bombest:sign` | Sign individual AU components |
| `/bombest:version` | Bump version across plugin headers |

Scripts in `.bombest-plugin-builder/scripts/` are native AU/VST2 wrappers (not JUCE). Signing identity: `Developer ID Application: Bombest, LLC (8C4A8V568P)`. Notarization profile: `notarytool`.
